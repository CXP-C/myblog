## 欢迎来到我的博客

这是我的第一篇示例文章。博客不只是发布文章的地方，也可以用来整理学习笔记、记录项目进度，或者分享生活中的新发现。

接下来，我会逐步补充真正想写的内容。你也可以把这篇文章当作模板：替换标题、日期、简介和正文，就能开始发布自己的文章。

## 用 Markdown 写作

文章正文支持常见的 Markdown 格式：

- 用标题组织内容层级；
- 用 **粗体** 突出重点，也可以用 *斜体* 补充语气；
- 用链接引用[项目文档](https://docs-firefly.cuteleaf.cn/)；
- 用 `行内代码` 标记命令、变量或文件名。

### 添加代码块

代码块适合分享命令和配置示例：

```bash
pnpm install
pnpm dev
```

### 整理信息

需要对照说明时，可以使用表格：

| 内容 | 示例 |
| --- | --- |
| 文章标题 | 你好，Firefly |
| 文章分类 | 博客指南 |
| 标签 | 博客、Firefly |

:::tip
发布前记得修改 frontmatter 中的标题、发布日期和简介。封面图可以留空；如果要添加图片，先确认图片文件也一并提交到仓库。
:::
